# 01：把 CLI 拆成按命令的模块

**要构建什么：** 同一个 `lgw` 二进制，每个子命令的实现放进各自的模块，配置路径解析、颜色决策和表格辅助集中到一处共享。这是纯机械移动：行为、输出、退出码、参数都不变。它的意义在于让后续切片能把某个命令的规则抽进 CLI 与控制台共用的操作层。

**依赖：** 无（可立即开始）。

- [ ] 现有 CLI 测试一条不改、全部通过。
- [ ] 每个子命令都有自己的模块；共享的路径、颜色和表格代码只有一个家。
- [ ] 每个命令的 `lgw --help`、输出字节和退出码都不变。
- [ ] `cargo test`、`cargo clippy --all-targets -- -D warnings`、`cargo fmt --check` 通过。
