# 控制台是只绑 loopback 的运维界面

[English](0001-browser-console.md) | **简体中文**

README 以前把 Web UI 列在明确不做里。改路由、改价格、改策略，只能去改配置文件、跑 CLI
命令 —— 对一个握着付费凭据的进程来说，这是刻意的。现在同一个二进制里带上了浏览器控制台：
改配置、看用量是运维做得最多的事，而文件是其中最慢的一环。明确不做只是收窄了，没有取消：
控制台只绑 loopback，没有登录、cookie 或会话，也不碰 `/v1` 契约。它是单个运维的工具，
不是第二个客户端 API，也不是多用户管理面板。

## 考虑过的选项

- 终端 UI：完全不碰浏览器，但没有图表，终端忙着的时候也没法用。如果运维从不离开这台机器、
  也从不想开浏览器，它仍然是更好的工具。
- 一个独立的伴随服务：它会重复配置解析、凭据访问和账本读取，还会打破单二进制安装的承诺。

## 后果

- `README.md` 不再把 Web UI 列在范围之外；防止控制台变成一扇敞开的大门的
  访问与同源规则在 `docs/web-ui.md` 里。
- 控制台是公开界面，需要自己的 Host、Origin 和 loopback 检查测试（见 `docs/web-ui.md`）。
