# 12：用量页与 ledger 索引

**要构建什么：** 用量页从账本回答花费与流量问题：随时间的 Covered 与 Metered 花费、token 数与缓存命中率、请求与失败计数、24 小时 / 7 / 30 / 90 天 / 全部的范围、按 provider、model、account 或 day 分组、只读连接、按币种分开的精确 Decimal 合计，并注明延迟历史只到 30 天。账本只增加这个功能需要的索引；现有行与金额格式不变。

**依赖：** 01（把 CLI 拆成按命令的模块）、04（控制台入口壳与最小看板）。

- [ ] 用量按选定范围与分组分别渲染 Covered 与 Metered。
- [ ] 金额合计精确、按币种分开，并与账本一致；缺失窗口被省略而不是补零。
- [ ] 延迟数据只到 30 天，页面说明原因。
- [ ] 用量页不访问 provider，只用只读账本连接。
- [ ] `lgw usage` 输出字节不变，并且现在与页面共用同一份聚合。
- [ ] schema 版本因建索引而前进；现有数据库迁移不重写任何行。
- [ ] 两种语言渲染同样的数字；图表带文字摘要。
- [ ] `cargo test`、`clippy --all-targets -- -D warnings`、`fmt --check` 通过。
