# 16：Keys 页

**要构建什么：** Keys 页列出每个已配置 Account 的凭据来源（凭据库、环境变量、文件、存在字面量），并允许运维添加、测试、移除 provider key。key 只写进操作系统的凭据库，任何响应或日志都不返回它；测试中使用内存凭据后端。`lgw keys` 共用这些操作，输出字节不变。

**依赖：** 01（把 CLI 拆成按命令的模块）、04（控制台入口壳与最小看板）。

- [ ] 页面列出每个 Account 的来源，从不显示值；原始 TOML 视图保持打码。
- [ ] 添加 key 只写凭据库；测试会探测 provider；移除只删除已存凭据。
- [ ] 任何页面、片段、响应头或日志行都不包含 key 值。
- [ ] 这些动作要求控制台的 JSON 与自定义头守卫。
- [ ] `lgw keys` 输出字节不变，并共用这些操作。
- [ ] 两种语言渲染同样的字段。
- [ ] `cargo test`、`clippy --all-targets -- -D warnings`、`fmt --check` 通过。
