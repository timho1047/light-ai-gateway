# 06：只读配置页

**要构建什么：** 一个配置页，显示网关真正在跑的东西：解析出的文件路径、内容指纹、最近应用时间、每个已知区段（policy、providers、accounts、routes、prices）的结构化只读视图、每个字段的 live / 仅重启生效 标记，以及一份把字面密钥打码的只读原始 TOML 视图。这个页面上什么都不写。

**依赖：** 04（控制台入口壳与最小看板）。

- [ ] 页面显示解析出的路径、它读取的文件指纹和最近应用时间。
- [ ] 每个已知区段和字段都渲染出来；live 与仅重启生效字段用不同标记区分。
- [ ] 原始 TOML 视图把字面密钥打码，任何响应都不携带原始文件字节。
- [ ] 页面在两种语言下渲染同样的数值。
- [ ] `cargo test`、`clippy --all-targets -- -D warnings`、`fmt --check` 通过。
