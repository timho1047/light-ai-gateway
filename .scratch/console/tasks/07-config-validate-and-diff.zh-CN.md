# 07：校验草稿并展示 diff

**要构建什么：** 配置页可以提交草稿：服务端把它应用到现有文档（保留注释、键顺序和未知键），用每个命令都在用的同一套规则校验整份配置，并返回按页面语言渲染的字段级错误，以及这次改动的 TOML diff。这个切片不写磁盘。

**依赖：** 06（只读配置页）。

- [ ] 合法草稿返回它将改动的确切 TOML diff。
- [ ] 非法草稿回 422，带字段级错误，按请求语言从稳定的错误码渲染；CLI 仍原样打印现有英文消息。
- [ ] 注释、键顺序和未知键在经过文档编辑后保留。
- [ ] 这个切片没有任何代码路径会写配置文件。
- [ ] 两种语言渲染同样的错误与 diff。
- [ ] `cargo test`、`clippy --all-targets -- -D warnings`、`fmt --check` 通过。
