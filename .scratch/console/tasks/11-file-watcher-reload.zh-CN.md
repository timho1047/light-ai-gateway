# 11：通过文件监视器重载外部改动

**要构建什么：** 在编辑器里改配置文件现在与控制台保存一样生效。监视器发现文件变化（包括基于 rename 的保存），把它交给同一条串行应用路径；控制台自己的保存不会触发第二次应用。非法的外部改动保留运行中的快照，并在日志和配置页上报；运维修好文件后它会自动再次应用。

**依赖：** 09（应用 provider 与 account 改动）、10（应用 route、别名与 price 改动）。

- [ ] 外部改动通过同一引擎应用，遵守同样的 live / 仅重启生效规则。
- [ ] 控制台保存不会经由监视器触发第二次应用。
- [ ] 非法的外部改动让旧快照继续服务，并在配置页和日志里暴露失败原因。
- [ ] 之后修好文件无需重启或再点控制台即可应用。
- [ ] 内容未变的文件不会被应用。
- [ ] `cargo test`、`clippy --all-targets -- -D warnings`、`fmt --check` 通过。
